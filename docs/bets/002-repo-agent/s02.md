# Slice 2: worktree start / finish (+ polish P1, P2)

## Demo
1. I put a test handoff `h900` (status ready, branch `test/h900-demo`) in the queue.
2. Cowork: `start_worktree("h900")` → Jean approves → `~/workspaces/mafx/worktrees/h900/` exists on `test/h900-demo`,
   `.env` copied, `uv sync` done; `workspace_status` lists it; reply ends with `cd … && claude "/handoff h900"`.
3. Cowork: `start_worktree("h003")` → refused: "h003 is draft, not ready" (checklist works).
4. Cowork: `finish_worktree("h900")` → Jean approves → worktree removed, branch deleted (it has no commits, so it is
   merged), `h900` moved to `.handoffs/done/`.
5. Jean: `mafx run repo-agent/agent`, "start h900" → mafx asks for approval → same result as step 2.
6. Every reply starts with text, not blank lines (P1); long PR titles are cut at 60 characters (P2).

## Design
```
 Cowork ─MCP─► start_worktree(handoff_id)   finish_worktree(name)        [write, Cowork approval]
 Jean ─mafx──► agent: skills start-worktree / finish-worktree ─► same functions [write, mafx approval]
                         │
                 repo_agent/worktree.py
                   start:  read .handoffs/<id>-*.md (status ready, branch) · main clean ·
                           git fetch origin --prune · git worktree add worktrees/<id> -b <branch> origin/main
                           (or add <branch> if it exists) · copy .env · uv sync --all-packages
                   finish: worktree clean · git fetch origin --prune · merged? (merge-base --is-ancestor)
                           yes: git worktree remove + git branch -d · no but pushed: remove, keep branch · else refuse
                           handoff file → .handoffs/done/ (if present)
                         │
                 guards.py: PathGuard · Allowlist (+ {branch}, {range}) · ActionLog
```
| Item | Decision |
|---|---|
| Worktree path | `worktrees/<handoff id>` (the queue id is the name everywhere) |
| New allowlist patterns | `git fetch origin --prune` · `git worktree add {path} -b {branch} origin/main` · `git worktree add {path} {branch}` · `git worktree remove {path}` · `git branch -d {branch}` · `git merge-base --is-ancestor {branch} origin/main` · `git rev-parse --verify --quiet {branch}` · `git rev-list --count {range}` · `uv sync --all-packages` |
| `{branch}` | `[A-Za-z0-9._/-]+`, no leading `-`, no `..` |
| `{range}` | `origin/{branch}..{branch}` only (unpushed-commit check) |
| File operations | `.env` copy and handoff move are Python file operations behind the PathGuard |
| P1 | host strips leading whitespace from the first text of a turn (`maf_labs_host`), so every agent benefits |
| P2 | `workspace_status` cuts PR titles at 60 characters |
| Build cycle docs | `/wt-new`, `/wt-done` marked deprecated in favour of the two tools |
