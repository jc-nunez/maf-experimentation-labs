## Design
```
 Claude desktop ──stdio──► repo_agent/mcp_server.py           mafx run repo/agent
   (Cowork)                  create_workspace   [write]          │
                             workspace_status   [read]           │
                             ask_repo_agent     [read, Qwen] ────┤
                                  │                              ▼
                                  │                 agents/agent.py: create_harness_agent
                                  │                   skill workspace-status · read tools only
                                  ▼                              │
                 repo_agent/workspace.py   create_workspace(project, repos) · workspace_status(project)
                 repo_agent/guards.py      PathGuard(root) · Allowlist(argv patterns) · ActionLog
                 repo_agent/git.py         run(argv) ─► Allowlist ─► subprocess (git, gh)
```
| Item | Decision |
|---|---|
| Root | `~/workspaces/` (override `REPO_AGENT_ROOT`); project folder `~/workspaces/<project>/` |
| Config | `.repo-agent/config.yaml`: `project`, `repos: [{name, url, default_branch}]` |
| Action log | `.repo-agent/actions.jsonl`: time, caller (mcp, mafx), tool, argv, result |
| Allowlist (slice 1) | `git clone <https url>`, `git status --porcelain`, `git rev-list --count`, `git worktree list --porcelain`, `git log -1`, `gh pr list --json ...` |
| Handoff queue | read from `<workspace>/<repo>/.handoffs/` |
| MCP stack | Python MCP SDK (FastMCP), stdio; console script `repo-agent-mcp` |
| Desktop registration | `claude_desktop_config.json`: `"repo-agent": {"command": "uv", "args": ["--directory", "<maf-experimentation-labs path>", "run", "repo-agent-mcp"]}` |
| Existing checkout | stays where it is; moving Jean's work to the workspace is a later decision (R13) |
