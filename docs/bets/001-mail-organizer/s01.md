# Slice 1: Triage report, outlook.com, read-only

## Demo
When done, I can run `mafx run mail/triage -p "last 7 days"` and see a table of my outlook.com mail grouped into
**needs me · newsletters · receipts · notifications · noise**, plus the top senders by volume. No message is changed.

## Design (this slice only)
```
 mafx run mail/triage
      │
      ▼
 triage agent (python, local Qwen) ──► tool mail_digest(account, days, max_messages)
                                             │
                                             ▼
                                   Graph: GET /me/mailFolders/inbox/messages
                                   $filter receivedDateTime ge <since>
                                   $select from,subject,receivedDateTime,isRead,bodyPreview,inferenceClassification
                                   $top 100, follow @odata.nextLink
                                             │
                                   token from MSAL cache (.mafx/secrets/mail/outlook-<alias>.bin)
```
- **Project:** `projects/mail`, python package `mail_agent`; agent `triage`; tool `mail-digest`.
- **Auth:** MSAL `PublicClientApplication`, authority `https://login.microsoftonline.com/consumers`, device code flow,
  scopes `Mail.Read`, `offline_access`. Client id from `.env`: `MAIL_OUTLOOK_CLIENT_ID`. Cache: `msal.SerializableTokenCache`
  persisted to `.mafx/secrets/mail/outlook-<alias>.bin`, chmod 600. The tool refreshes silently; if no valid token, it
  fails with "run: uv run python -m mail_agent.auth outlook --alias <alias>".
- **Tool `mail_digest`:** returns `{account, since, total, unread, senders: [{name, address, count, unread, focused_ratio,
  samples: [{subject, preview(160), received}] (max 3)}]}` sorted by count. Grouping happens in code so the model
  classifies senders, not thousands of messages. `max_messages` default 500.
- **Agent instructions:** classify each sender group into the five buckets; output one markdown table per bucket
  (sender, count, unread, why); then "Top 10 senders by volume"; then "Needs me" first in the answer. No actions.
- **HTTP:** `httpx`, with a module-level transport hook for tests (same pattern as `tools/python/web-search`).
