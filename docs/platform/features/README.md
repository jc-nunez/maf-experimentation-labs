# Features (L2)

One file per feature: `<area>-<feature>.md`, e.g. `a02-f3-event-stream.md`, from `docs/process/templates/feature.md`.
A feature holds the requirements (IDs like `A2.F3.R1`). Items (`docs/work/NNN-slug/`) select requirements from
one or more features and carry the design and the plan.
