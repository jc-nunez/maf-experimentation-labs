# repo-agent

Repo agent: mafx workspace, read-only status, MCP server for Cowork (bet 002)

```bash
mafx show repo-agent                 # components
mafx run repo-agent/<agent> -p "hi"  # run once
mafx run repo-agent/<agent>          # interactive
mafx new agent repo-agent <agent-name> --runtime python|declarative|dotnet
```
